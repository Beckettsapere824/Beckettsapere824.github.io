Connect MCP (Grok)

Grok custom MCP: name + server URL. Same pattern as other remote MCP servers.

Feasible: Website account (user + password) → issue per-user API token → user pastes MCP URL + token into Grok.
Not best: Putting the website password into the MCP client. Use a rotatable token. Shared/org tokens are worse.

Grok steps

  1. Open Grok MCP / connectors → add custom server
  2. Name: noesyx-memory (any label)
  3. URL: https://noesyx-lab.com/mcp (live after backend + DNS)
  4. Auth: Bearer / header with your API token from Account (not password)

Example config shape

{
  "name": "noesyx-memory",
  "url": "https://noesyx-lab.com/mcp",
  "headers": {
    "Authorization": "Bearer nl_xxx_your_token"
  }
}

What the server should expose (later)

  • search_nodes / read_node
  • list_tasks
  • append_inbox (optional write)
