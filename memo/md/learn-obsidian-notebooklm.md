# What to copy from Obsidian & NotebookLM

Closes task from thought: survey related schemes; copy the useful part first.

## Obsidian (local graph notes)

| Pattern | Copy into ex-memo-rick? | How |
|---------|-------------------------|-----|
| Atomic notes + wikilinks | **Yes** | nodes + compile edges |
| Tags + backlinks | **Yes** | frontmatter tags; tag views |
| Daily notes / inbox | **Yes** | `inbox/` drop zone |
| Graph visualization UI | Later / optional | `graph.json`; UI not the lever |
| Plugins ecosystem | **No** as dependency | Stay file-native for agents |

**Steal:** local-first markdown, cheap links, no mandatory cloud.

## NotebookLM (source-grounded synthesis)

| Pattern | Copy? | How |
|---------|-------|-----|
| Answers grounded in sources | **Yes** | cite node ids / paths |
| Auto study guides / FAQ | **Yes (lightweight)** | i2k views + collab MCQ |
| Audio overview | No for now | Not agent-native priority |
| Multi-source chat with folder | **Yes** | Playbooks: INDEX → nodes → answer |

**Steal:** synthesis always attributable to sources.
