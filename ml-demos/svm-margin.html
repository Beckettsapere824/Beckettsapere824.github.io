这是在演示什么？

硬间隔支持向量机要找一条直线，把两类点完全分开，并且让中间的“间隔带”尽可能宽。

间隔带的两条边界（黄线）刚好碰到一些点——这些点就叫支持向量。只有它们决定了直线的位置；其他点再怎么动，只要不越界，边界都不变。

怎么操作

  • 添加点：选择 “+ Positive” 或 “− Negative”，在画布上点击。
  • 拖动点：切到 “Drag”，按住点拖动，观察边界如何变化。
  • 关键实验：先拖动一个没有黄圈的点——边界几乎不动。再拖动一个有黄圈的支持向量——整个间隔带立刻旋转或平移。

图例

正类点 (+1) 负类点 (−1) 支持向量（决定边界） 决策边界 w·x + b = 0 间隔边界 w·x + b = ±1

为什么这很重要？

对偶问题里，只有 αi > 0 的样本会出现在最终的 w 展开式中。这些样本就是支持向量。这就是“稀疏性”的几何来源——也是 SVM 预测时只需要支持向量的原因。
