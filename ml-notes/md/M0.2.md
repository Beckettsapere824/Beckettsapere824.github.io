# M0.2 Norms ($\ell_{1}$, $\ell_{2}$, $\ell_{\infty}$) and Distance Metrics

**Prerequisites / 前置**: [M0.1 Vectors & Inner Product](M0.1.md)

---

## What problem? / 要解决什么？

M0.1 gave Euclidean length. Real systems often need other rulers: taxicab geometry, worst-axis deviation, etc. Different rulers change which point is “nearest”—and that changes k-NN.

M0.1 给了欧氏长度。实际系统还需要别的尺子：只能横平竖直走的距离、最差一维的偏差等等。尺子不同，「谁最近」会变——k-NN 的预测也会变。

---

## Step 1: What is a norm? / 第一步：范数是什么？

A norm $\lVert \cdot \rVert$ assigns a nonnegative length to each vector, with:

范数给每个向量一个非负「长度」，并满足：

1. $\lVert \mathbf{x} \rVert = 0 \Leftrightarrow \mathbf{x}=\mathbf{0}$ (positive definite / 正定)  
2. $\lVert c\mathbf{x} \rVert = |c|\,\lVert \mathbf{x} \rVert$ (homogeneity / 齐次)  
3. $\lVert \mathbf{x}+\mathbf{y} \rVert \le \lVert \mathbf{x} \rVert + \lVert \mathbf{y} \rVert$ (triangle inequality / 三角不等式)

Distance induced by a norm: $d(\mathbf{x},\mathbf{y})=\lVert \mathbf{x}-\mathbf{y} \rVert$.

由范数诱导的距离：$d(\mathbf{x},\mathbf{y})=\lVert \mathbf{x}-\mathbf{y} \rVert$。

---

## Step 2: Three common norms / 第二步：三种常用范数

$$
\lVert \mathbf{x} \rVert _{1} = \sum_{i} |x_{i}|,\qquad
\lVert \mathbf{x} \rVert _{2} = \sqrt{\sum_{i} x_{i}^{2}},\qquad
\lVert \mathbf{x} \rVert _{\infty} = \max_{i} |x_{i}|.
$$

**Unit balls look different / 单位球长得不同:**

- $\ell_{2}$: sphere / 圆（球）  
- $\ell_{1}$: diamond / 菱形  
- $\ell_{\infty}$: square (cube) / 正方形（立方体）

Same “length 1” set, radically different shape ⇒ different nearest-neighbour relations.

同样是「长度 1」的点集，形状完全不同 ⇒ 最近邻关系不同。

---

## Step 3: One example, three distances / 第三步：同一组点，三种距离

Points: $\mathbf{a}=(0,0)$, $\mathbf{b}=(1,1)$, $\mathbf{c}=(2,0)$.

| Metric | $d(\mathbf{a},\mathbf{b})$ | $d(\mathbf{a},\mathbf{c})$ | Who is closer to $\mathbf{a}$? |
|--------|---------------------------|---------------------------|--------------------------------|
| $\ell_{2}$ | $\sqrt{2}\approx 1.41$ | $2$ | $\mathbf{b}$ |
| $\ell_{1}$ | $2$ | $2$ | tie / 平局 |
| $\ell_{\infty}$ | $1$ | $2$ | $\mathbf{b}$ |

So the ranking is **metric-dependent**. In M1 this becomes: the 1-NN classifier is not fully specified until you fix the norm.

排序 **依赖度量**。到了 M1：不定下范数，1-NN 分类器就还没定义完。

---

## Step 4: Finite dimensions are “equivalent” but not interchangeable / 第四步：有限维等价但不互换

In finite dimension all norms give the same convergent sequences (topological equivalence), but **geometry and algorithms care about the shape**. Regularisation later will also choose $\lVert \mathbf{w} \rVert _{1}$ vs $\lVert \mathbf{w} \rVert _{2}^{2}$ for different sparsity behaviour.

有限维中所有范数拓扑等价（同样的收敛性），但 **几何与算法在乎形状**。后面正则化也会在 $\lVert \mathbf{w} \rVert _{1}$ 与 $\lVert \mathbf{w} \rVert _{2}^{2}$ 之间选择，以得到不同稀疏性。

---

## Practice / 练习

For $\mathbf{q}=(1,0)$, which of $\mathbf{a},\mathbf{b},\mathbf{c}$ above is nearest under each of the three norms?

对 $\mathbf{q}=(1,0)$，在三种范数下 $\mathbf{a},\mathbf{b},\mathbf{c}$ 谁最近？

<details>
<summary>Answer / 答案</summary>

$\ell_{2}$ and $\ell_{\infty}$: $\mathbf{a}$ and $\mathbf{c}$ both at distance 1 (tie). $\ell_{1}$: all three at distance 1.

$\ell_{2}$ 与 $\ell_{\infty}$：$\mathbf{a}$ 与 $\mathbf{c}$ 都是 1（平局）。$\ell_{1}$：三个都是 1。

</details>

---

```python
from numpy.linalg import norm
import numpy as np
a, b, c = np.array([0.,0.]), np.array([1.,1.]), np.array([2.,0.])
print(norm(a-b,1), norm(a-b,2), norm(a-b,np.inf))
```
