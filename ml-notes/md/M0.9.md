# M0.9 Convex Sets, Convex Functions, First-order Characterisation

**Prerequisites / 前置**: [M0.7](M0.7.md)

---

## What problem? / 要解决什么？

People say “convex problems are easy.” Easy because a local minimum is automatically global—there are no false valleys.

常说「凸问题好算」。因为局部最小自动是全局最小——没有假山谷。

---

## Convex set / 凸集

$C$ is convex if $t\mathbf{x}+(1-t)\mathbf{y}\in C$ for all $\mathbf{x},\mathbf{y}\in C$, $t\in[0,1]$.

任意两点连线段仍在集合内。

---

## Convex function / 凸函数

$$
f(t\mathbf{x}+(1-t)\mathbf{y})\le t f(\mathbf{x})+(1-t)f(\mathbf{y}).
$$

Graph lies below chords. Squared loss is convex; deep-net losses usually are not.

图像在弦下方。平方损失凸；深度网络损失通常不凸。

---

## First-order characterisation / 一阶刻画

$$
f(\mathbf{y})\ge f(\mathbf{x})+\nabla f(\mathbf{x})^{\top}(\mathbf{y}-\mathbf{x}).
$$

If $\nabla f(\mathbf{x}^{*})=\mathbf{0}$, then $\mathbf{x}^{*}$ is a **global** minimiser.

梯度为零则全局最小。
