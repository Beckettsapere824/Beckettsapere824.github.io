# M2.1 Linear Regression – Model & Squared Loss

**Prerequisites / 前置**: [M0.8](M0.8.md)

---

## What problem? / 要解决什么？

k-NN remembers every point. Linear regression compresses data into $\hat{y}=\mathbf{w}^{\top}\mathbf{x}$.

k-NN 记住每个点；线性回归压成 $\hat{y}=\mathbf{w}^{\top}\mathbf{x}$。

$$
J(\mathbf{w})=\tfrac{1}{2}\lVert X\mathbf{w}-\mathbf{y}\rVert_{2}^{2}.
$$

Squared loss: differentiable, penalises large errors, Gaussian MLE.

平方损失：可微、重罚大误差、对应高斯 MLE。
