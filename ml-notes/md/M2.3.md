# M2.3 Feature Maps & Polynomial Regression

**Prerequisites / 前置**: [M2.2](M2.2.md)

---

Keep linear-in-$\mathbf{w}$ model with richer features $\phi(\mathbf{x})$:

$$
\hat{y}=\mathbf{w}^{\top}\phi(\mathbf{x}).
$$

Polynomial 1D: $\phi(x)=(1,x,\ldots,x^{p})^{\top}$. Same normal equations on design matrix $\Phi$. Higher $p$ overfits; use validation / ridge.

对 $\mathbf{w}$ 线性、对 $\mathbf{x}$ 可非线性。$p$ 过大易过拟合。
