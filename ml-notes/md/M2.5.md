# M2.5 Perceptron Learning Rule

**Prerequisites / 前置**: [M0.1 Vectors](M0.1.md), [M0.8 Matrix calculus](M0.8.md)

---

## What problem? / 要解决什么？

Regression predicts a number. Now labels are $\pm 1$ and we only care about the **side** of a hyperplane. The perceptron is the oldest rule that updates itself only when it is wrong.

回归预测数值。现在标签是 $\pm 1$，只关心超平面的 **哪一侧**。感知机是最古老的「只在犯错时更新」规则。

---

## Step 1: Linear classifier / 第一步：线性分类器

$$
\hat{y} = \mathrm{sign}(\mathbf{w}^{\top}\mathbf{x}),
\qquad
\mathrm{sign}(z)=\begin{cases}+1&z\ge 0\\-1&z<0.\end{cases}
$$

(Include a constant feature $1$ if you want a bias $b$.)

（需要偏置时加入常数特征 $1$。）

---

## Step 2: The update / 第二步：更新

If sample $i$ is **misclassified**, i.e. $y_{i}(\mathbf{w}^{\top}\mathbf{x}_{i})\le 0$, set

若样本 $i$ **分错**，即 $y_{i}(\mathbf{w}^{\top}\mathbf{x}_{i})\le 0$，则

$$
\mathbf{w}\leftarrow\mathbf{w}+y_{i}\mathbf{x}_{i}.
$$

Correct predictions leave $\mathbf{w}$ unchanged. Intuition: add $y_{i}\mathbf{x}_{i}$ pushes the score $y_{i}\mathbf{w}^{\top}\mathbf{x}_{i}$ upward by $\lVert\mathbf{x}_{i}\rVert_{2}^{2}$.

分对则不动。直观：加上 $y_{i}\mathbf{x}_{i}$ 会把 $y_{i}\mathbf{w}^{\top}\mathbf{x}_{i}$ 抬高 $\lVert\mathbf{x}_{i}\rVert_{2}^{2}$。

---

## Step 3: Convergence / 第三步：收敛

If the training set is **linearly separable**, the perceptron finds a separating $\mathbf{w}$ in a finite number of updates (perceptron convergence theorem). If not separable, the weights keep oscillating—there is no “done.”

训练集 **线性可分** 时，有限步内找到分隔 $\mathbf{w}$。不可分则权重持续振荡，没有「完成」。

---

## Step 4: Loss view / 第四步：损失视角

The update is a subgradient step on the perceptron loss $\sum_{i}\max(0,-y_{i}\mathbf{w}^{\top}\mathbf{x}_{i})$. Only violated constraints contribute.

更新是感知机损失 $\sum_{i}\max(0,-y_{i}\mathbf{w}^{\top}\mathbf{x}_{i})$ 的次梯度步，只有被违反的约束有贡献。

---

## Practice / 练习

$\mathbf{w}=(0,0)^{\top}$, $\mathbf{x}=(1,1)^{\top}$, $y=+1$. Is it misclassified? After one update, what is $\mathbf{w}$?

<details>
<summary>Answer / 答案</summary>

Score $0$, treated as misclassified (or on the boundary). $\mathbf{w}\leftarrow(1,1)^{\top}$.

分数为 $0$，视为错分；$\mathbf{w}\leftarrow(1,1)^{\top}$。

</details>
