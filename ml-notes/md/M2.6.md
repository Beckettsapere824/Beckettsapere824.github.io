# M2.6 Adaline & Continuous Activation

**Prerequisites / 前置**: [M2.5 Perceptron](M2.5.md), [M2.1 Linear regression](M2.1.md)

---

## What problem? / 要解决什么？

The perceptron only asks “right or wrong?” Adaline asks “how wrong?” by using a **continuous** output and squared error—so ordinary gradient descent applies even when data are not separable.

感知机只问「对还是错」。Adaline 用 **连续** 输出与平方误差问「错多少」——数据不可分时也能用普通梯度下降。

---

## Step 1: Continuous score / 第一步：连续分数

$$
\hat{y}_{\mathrm{raw}}=\mathbf{w}^{\top}\mathbf{x},
\qquad
J(\mathbf{w})=\tfrac{1}{2}\sum_{i}(\mathbf{w}^{\top}\mathbf{x}_{i}-y_{i})^{2}.
$$

Labels may still be $\pm 1$; the loss treats them as real targets. Final class prediction is $\mathrm{sign}(\mathbf{w}^{\top}\mathbf{x})$.

标签仍可为 $\pm 1$，损失把它们当实数目标。最终类别取符号。

---

## Step 2: Same as least squares / 第二步：就是最小二乘

Matrix form is exactly $J=\tfrac{1}{2}\lVert X\mathbf{w}-\mathbf{y}\rVert_{2}^{2}$. Gradient and GD step match M2.1 / M2.4:

矩阵形式与最小二乘相同。梯度与 GD 步同 M2.1 / M2.4：

$$
\mathbf{w}\leftarrow\mathbf{w}-\eta X^{\top}(X\mathbf{w}-\mathbf{y}).
$$

---

## Step 3: Contrast with perceptron / 第三步：对比感知机

| | Perceptron | Adaline |
|--|------------|---------|
| Output used in loss | $\mathrm{sign}$ | raw score |
| When to update | only if wrong | every sample (batch/SGD) |
| Separability | required for convergence | not required |

感知机只在分错时更新；Adaline 每步都更新，不可分也会收敛到某个最小点。

---

## Practice / 练习

Why can Adaline converge on a non-separable set while the classical perceptron does not stop?

<details>
<summary>Answer / 答案</summary>

Adaline minimises a convex smooth $J$ with a global minimiser; the perceptron keeps firing updates whenever any point is misclassified, which never ends if no separator exists.

Adaline 最小化凸光滑 $J$，有全局最小；感知机在仍有错分点时一直更新，无分隔面则不停。

</details>
