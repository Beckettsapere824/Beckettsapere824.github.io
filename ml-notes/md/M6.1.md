# M6.1 Majority / Plurality Voting & Weighted Voting

**Prerequisites / 前置**: none (uses classification intuition from M1–M2)

---

## What problem? / 要解决什么？

One model makes mistakes. Several models make *different* mistakes. Combining them can cancel errors—if their errors are not identical.

单个模型会犯错。多个模型犯 *不同* 的错。若错误不完全相同，合成可以抵消错误。

---

## Step 1: Hard (majority) vote / 第一步：硬投票

Each classifier $h_{t}$ outputs a label. The ensemble predicts the label that receives the most votes (plurality if more than two classes).

每个分类器 $h_{t}$ 输出标签；集成取得票最多的标签（多类时为相对多数）。

**Tiny example / 小例子.** Three models vote $(A,A,B)$ → ensemble says $A$.

---

## Step 2: Soft vote / 第二步：软投票

If models output probabilities, average the probability vectors and then take $\arg\max$. Soft voting uses confidence, not only hard labels.

若模型输出概率，先平均概率向量再 $\arg\max$。软投票利用置信度，不只看硬标签。

---

## Step 3: Weighted vote / 第三步：加权投票

Assign weight $w_{t}$ (e.g. validation accuracy) to model $t$. Higher weight → more say. AdaBoost later *learns* such weights from training errors.

给模型 $t$ 权重 $w_{t}$（如验证准确率）。权重大 → 话语权大。AdaBoost 之后会从训练误差 *学出* 这类权重。

---

## Step 4: Correlation warning / 第四步：相关性警告

If all models always agree, voting changes nothing. Diversity (different errors) is the resource Bagging and Boosting try to create systematically.

若所有模型总一致，投票无用。多样性（不同错误）才是 Bagging / Boosting 要系统制造的资源。

---

## Practice / 练习

Probabilities for class $A$ from three models: $0.6,0.55,0.1$. Soft-vote probability for $A$? Hard votes if threshold $0.5$?

<details>
<summary>Answer / 答案</summary>

Soft: $(0.6+0.55+0.1)/3=0.417$. Hard votes: $A,A,B$ → majority $A$.

软投票 $0.417$；硬投票多数为 $A$。

</details>
