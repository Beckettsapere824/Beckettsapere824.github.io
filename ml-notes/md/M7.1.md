# M7.1 Entropy & Information Gain

**Prerequisites / 前置**: none (basic probability helpful)

---

## What problem? / 要解决什么？

A decision tree asks questions about features to separate labels. We need a score for “how mixed are the labels here?” and “how much did this split clean them up?”

决策树靠问特征来分开标签。需要度量「这里的标签有多乱」以及「这次分裂让混乱降了多少」。

---

## Step 1: Entropy / 第一步：熵

For a node with class proportions $p_{1},\ldots,p_{C}$,

节点中各类比例 $p_{1},\ldots,p_{C}$，

$$
H=-\sum_{c=1}^{C}p_{c}\log_{2}p_{c}
$$

(with $0\log 0:=0$). Pure node ($p=1$ for one class): $H=0$. Uniform distribution: maximum entropy.

纯节点熵为 $0$；均匀分布熵最大。

**Example / 例子.** Labels $(+,+,+,-)$ → $p_{+}=3/4$, $p_{-}=1/4$,
$H=-\tfrac{3}{4}\log_{2}\tfrac{3}{4}-\tfrac{1}{4}\log_{2}\tfrac{1}{4}\approx 0.81$ bits.

---

## Step 2: Information gain / 第二步：信息增益

Split $S$ into subsets $S_{1},\ldots,S_{m}$ by a feature. Gain is

按某特征把 $S$ 分成 $S_{1},\ldots,S_{m}$。增益为

$$
\mathrm{IG}=H(S)-\sum_{j}\frac{|S_{j}|}{|S|}H(S_{j}).
$$

Large gain = the feature separates classes well. Prefer the split with largest IG at each node (ID3-style).

增益大 = 该特征把类分得更开。每节点选增益最大的分裂（ID3 风格）。

---

## Step 3: Bias toward many values / 第三步：偏向多取值特征

A feature with a unique value per row can drive child entropies to zero and look perfect—while generalising poorly. Gain ratio (C4.5) penalises such splits; CART instead uses binary splits and Gini (next nodes).

每行取值都不同的特征可把子节点熵打到 0，看似完美却难泛化。增益率（C4.5）会惩罚；CART 改用二分与 Gini。

---

## Practice / 练习

Compute $H$ for six points with labels $(A,A,B,B,B,B)$.

<details>
<summary>Answer / 答案</summary>

$p_{A}=1/3$, $p_{B}=2/3$, $H=-\tfrac13\log_{2}\tfrac13-\tfrac23\log_{2}\tfrac23\approx 0.92$.

</details>
