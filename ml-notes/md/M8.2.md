# M8.2 Computational Graph & Forward Pass

**Prerequisites / 前置**: [M8.1 MLP](M8.1.md)

---

## What problem? / 要解决什么？

Nested formulas for deep nets are hard to differentiate by hand. A **computational graph** turns the model into local ops that we can run forward—and later reverse.

深层嵌套公式难手算导数。**计算图** 把模型变成可前向执行、稍后反向的局部运算。

---

## Step 1: Nodes and edges / 第一步：节点与边

Each node is an elementary op (matmul, add, ReLU, …). Edges carry arrays. A **topological order** of the graph is a valid forward evaluation order.

每个节点是基本运算；边上传数值。图的 **拓扑序** 即合法前向顺序。

---

## Step 2: Layer in matrix form / 第二步：矩阵形式的一层

For a minibatch $X\in\mathbb{R}^{B\times d}$ (rows = samples):

小批量 $X\in\mathbb{R}^{B\times d}$（行 = 样本）：

$$
Z=XW+\mathbf{1}\mathbf{b}^{\top},
\qquad
H=\varphi(Z).
$$

Stack such blocks; end with a loss node that compares predictions to targets.

堆叠这样的块；末端接比较预测与目标的损失节点。

---

## Step 3: Cache intermediates / 第三步：缓存中间量

Forward must **store** $Z,H,\ldots$ needed by backward local derivatives. Overwriting buffers in place without keeping values required for the chain rule breaks backprop.

前向必须 **保存** 反向局部导数需要的 $Z,H,\ldots$。原地覆盖且不留链式法则所需值会弄坏反传。

---

## Practice / 练习

List a valid forward order for: input → linear → ReLU → linear → softmax → cross-entropy.

<details>
<summary>Answer / 答案</summary>

Exactly that sequence (or any topological order consistent with those dependencies)—loss last.

按依赖顺序，损失在最后。

</details>
