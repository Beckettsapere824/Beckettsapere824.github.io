# M8.4 Training Loop, Mini-batch SGD, Practical Tricks

**Prerequisites / 前置**: [M8.3 Backprop](M8.3.md), [M2.4 Gradient descent](M2.4.md)

---

## What problem? / 要解决什么？

Gradients alone do not train a net. We need a **loop**, a step-size policy, careful initialisation, and regularisation—while watching train vs validation curves.

有梯度还不够。需要 **训练循环**、步长策略、初始化、正则，并监视训练/验证曲线。

---

## Step 1: The loop / 第一步：循环

```
for epoch:
  for minibatch (X, y):
    ŷ, cache = forward(X)
    J = loss(ŷ, y)
    grads = backward(J, cache)
    parameters ← parameters − η · grads
```

Mini-batches estimate the full gradient cheaply and add noise that can help escape sharp minima.

小批量廉价估计全梯度，噪声有时有助于逃离尖锐极小。

---

## Step 2: Learning rate / 第二步：学习率

Too large: loss diverges. Too small: crawls. Schedules (step decay, cosine) start larger and shrink. Adaptive methods (Adam) rescale per-parameter steps—still need a sensible base $\eta$.

过大发散，过小爬行。调度（阶梯、余弦）先大后小。Adam 等自适应方法仍需合理的基础 $\eta$。

---

## Step 3: Initialisation & regularisation / 第三步：初始化与正则

- **Init:** scale weights so activations neither explode nor vanish (e.g. He init for ReLU).  
- **Weight decay:** $L_2$ penalty on weights.  
- **Dropout:** randomly zero hidden units at train time.  
- **Data augmentation:** expand effective sample size.

- **初始化：** 控制激活方差（如 ReLU 用 He）。  
- **权重衰减：** $L_2$。  
- **Dropout：** 训练时随机屏蔽隐单元。  
- **数据增强：** 扩大有效样本。

---

## Step 4: Diagnose curves / 第四步：读曲线

| Train loss | Val loss | Likely issue |
|------------|----------|--------------|
| high | high | underfit / weak model / $\eta$ too small |
| low | high | overfit → regularise / more data / early stop |
| unstable | unstable | $\eta$ too large / bugs |

---

## Practice / 练习

Write why you should not pick the model with the lowest **training** loss alone.

<details>
<summary>Answer / 答案</summary>

Training loss can decrease by memorisation; validation (or test) loss measures generalisation.

训练损失可靠死记下降；验证/测试损失才反映泛化。

</details>
